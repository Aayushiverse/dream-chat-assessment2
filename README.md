# DREAM-CHAT (Assessment 2)

A secure multi-client chat application using AES encryption over TCP sockets.

## Features
- Multi-client chat server
- AES-CBC encryption with random IV
- SHA-512 + MD5 key derivation
- Configuration via `config.ini`
- Python 3 compatible

## Requirements
- Python 3.7+
- pycryptodome
